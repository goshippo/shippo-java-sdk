# Provider

To have insurance cover provided by a carrier directly instead of Shippo's provider (XCover), set `provider` to `FEDEX`, `UPS`, or `ONTRAC`.

## Example Usage

```java
import com.goshippo.shippo_sdk.models.components.Provider;

Provider value = Provider.FEDEX;
```


## Values

| Name     | Value    |
| -------- | -------- |
| `FEDEX`  | FEDEX    |
| `UPS`    | UPS      |
| `ONTRAC` | ONTRAC   |
