# VerificationOption

Determines the verification option to use for the account registration (Enum: SMS, EMAIL, CALL, INVOICE).

## Example Usage

```java
import com.goshippo.shippo_sdk.models.components.VerificationOption;

VerificationOption value = VerificationOption.SMS;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `SMS`     | SMS       |
| `EMAIL`   | EMAIL     |
| `CALL`    | CALL      |
| `INVOICE` | INVOICE   |
